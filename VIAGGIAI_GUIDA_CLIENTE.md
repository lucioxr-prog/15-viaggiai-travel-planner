## Cos'è ViaggiAI
Comparatore di viaggi: voli, hotel, treni, auto, meteo e attrazioni in un'unica schermata. Non vende biglietti — ti porta sui siti ufficiali per prenotare.

## Accesso
1. Apri https://lucioxr-prog.github.io/15-viaggiai-travel-planner
2. Clicca **Accedi con Google**
3. Autorizza con il tuo account Google

Serve un account Google. Non sono accettate email/password.

## Come cercare
| Campo | Cosa inserire |
|---|---|
| Partenza | Città (es. Milano) |
| Destinazione | Vuoto = suggerimenti automatici |
| Date | Andata e ritorno |
| Adulti | Numero viaggiatori |
| Budget | Economico / Medio / Premium |
| Trasporto | Volo / Treno / Auto / Indifferente |
| Alloggio | Hotel / B&B / Appartamento / Indifferente |

## Cosa trovi nei risultati
- Meteo previsto nel periodo
- Costo stimato volo + hotel (indicativo)
- Voli con orari, prezzo e link prenotazione
- Treni con link Trenitalia / Italo / Omio
- Hotel con stelle, prezzo e link Booking.com
- Auto con distanza e link noleggio
- Attrazioni nelle vicinanze
- Mappa interattiva

I prezzi sono indicativi. Verificare sempre sul sito di prenotazione.
